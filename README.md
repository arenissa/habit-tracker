# 🌿 Трекер привычек

Минималистичный трекер привычек: отметить привычку можно одним касанием,
серия и прогресс видны сразу. Без бэкенда и без лишнего шума.

- **Стек:** чистый HTML/CSS/JS (ES-модули), localStorage, PWA (офлайн).
- **Экраны:** «Сегодня», «Календарь привычки», «Создание/редактирование».
- **Правила серий и пропусков:** [docs/spec.md](docs/spec.md).
- **Тест-кейсы:** [docs/test-cases.md](docs/test-cases.md).
- **Кейс проекта:** [docs/case-study.md](docs/case-study.md).
- **Правила для ИИ-агента:** [AGENTS.md](AGENTS.md).

## Запуск

Зависимостей нет — нужен только любой статический сервер:

```
npx serve .
# или
python -m http.server 8000
```

Откройте `http://localhost:8000`. Через `file://` приложение не запускается:
ES-модули и service worker требуют http(s).

## Проверка на телефоне

1. Телефон и компьютер — в одной сети Wi-Fi.
2. Узнайте IP компьютера: `ipconfig` (Windows) → IPv4-адрес.
3. Откройте на телефоне `http://<IP>:8000`.
4. «Добавить на главный экран» — установится как PWA и будет работать офлайн.

## Структура

```
index.html            — единая страница-оболочка
styles.css            — mobile-first стили
manifest.webmanifest  — PWA-манифест
sw.js                 — service worker (network-first, кэш-фолбэк)
icon.svg              — иконка приложения
js/
  app.js              — точка входа: роутинг экранов, регистрация SW
  dates.js            — локальные даты (YYYY-MM-DD), месяцы, сетка календаря
  storage.js          — слой localStorage
  habits.js           — создание/редактирование/архив привычек
  marks.js            — отметки: поставить/снять (toggle)
  streak.js           — расчёт текущей и лучшей серии
  util.js             — экранирование HTML
  ui-today.js         — экран «Сегодня»
  ui-calendar.js      — календарь месяца
  ui-habit-form.js    — форма привычки
docs/
  spec.md             — ТЗ: серии, пропуски, критерии готовности
  test-cases.md       — ручные тест-кейсы
```

## Ограничения MVP (честно)

- Нет гибкого графика по дням недели, графиков статистики и напоминаний — план v2.
- PWA-иконка в SVG: для публикации в сторах понадобятся PNG-размеры.
- Данные живут в localStorage одного браузера: экспорт/синхронизация — v2.
- ИИ-сводка (опциональный пункт задания) не включена: потребует ключа в `.env`.

## Dev-заметки

- Service worker: network-first с фолбэком в кэш. Если при разработке видите
  устаревшую версию: DevTools → Application → Service Workers → Unregister.
- Линтера и автотестов нет (так требует задание): проверка — по чек-листу
  критериев готовности в [AGENTS.md](AGENTS.md) и docs/test-cases.md.
