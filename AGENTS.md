# AGENTS.md — Трекер привычек

## О проекте
Минималистичный трекер привычек: отметить выполнение одним касанием, серия (streak)
и прогресс видны сразу. Без бэкенда, данные — только в localStorage браузера. Mobile-first.

## Стек и запуск
- Чистый HTML/CSS/JS (ES-модули), без сборки и без фреймворков.
- Локальный запуск: `npx serve .` (или `python -m http.server 8000`) и открыть на телефоне
  в той же сети. Service worker требует http(s), `file://` не подходит.
- Автотесты/линтер не предусмотрены заданием — проверка ручная по чек-листу
  «Критерии готовности» ниже и по docs/test-cases.md.

## Структура проекта
- `docs/spec.md` — ТЗ: определение «серии» и правил пропуска дней.
- `docs/test-cases.md` — ручные тест-кейсы.
- `index.html`, `styles.css`, `js/*.js` — код приложения.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — PWA-обвязка.

## Модель данных (localStorage)
- Ключ `habits`: JSON-массив `{id, name, color, createdAt, archived}`.
- Ключ `marks`: JSON-массив `{habitId, date: "YYYY-MM-DD"}`.
- Дата — ВСЕГДА локальная строка "YYYY-MM-DD" из getFullYear/getMonth/getDate.
  Запрещено `toISOString().slice(0,10)` и любая логика по UTC/серверному времени —
  это типичная ошибка из задания.

## Критичные правила (нарушать нельзя)
1. Серия считается по локальной дате пользователя, а не по времени сервера/UTC.
2. Пропущенный день не отображается и не считается выполненным.
3. Серия корректно сбрасывается после пропуска (детали — в docs/spec.md).
4. Отметку можно снять одним касанием (отмена ошибочной отметки).
5. Данные переживают перезагрузку страницы и браузера.
6. Первый экран — без лишних настроек; интерфейс удобен одной рукой на телефоне.
7. Новый функционал MVP не расширяет: гибкий график, графики и напоминания —
   только после работающего MVP (v2).

## Стиль кода
- Vanilla JS, ES-модули, один файл — одна зона ответственности.
- Без комментариев в коде, если это не обязательная инвариант-документация.
- Коммиты: Conventional Commits (`feat:`, `fix:`, `docs:`), одно изменение — один коммит.
- Секреты — только в `.env`, никогда в промптах и репозитории.

## Критерии готовности (проверять перед каждым коммитом фичи)
- [ ] Отметки сохраняются после перезагрузки.
- [ ] Пропущенный день не показан как выполненный.
- [ ] Серия сбрасывается после пропуска.
- [ ] Ошибочную отметку можно снять.
- [ ] Интерфейс работает на телефоне одной рукой.
